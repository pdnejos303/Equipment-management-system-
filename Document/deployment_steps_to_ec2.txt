ขั้นตอนการนำระบบ EquipTrack ขึ้นเซิร์ฟเวอร์ AWS EC2 (ฉบับอัปเดตล่าสุด: Build Locally & Deploy)
========================================================================

เครื่องที่ใช้งาน: AWS EC2 (Ubuntu 24.04 LTS, t3.micro - RAM 1GB)
IP Address: 43.210.64.201

**ปัญหาที่พบ:**
เนื่องจากเครื่อง t3.micro มี RAM เพียง 1GB การรันคำสั่ง `npm run build` ของ Next.js บนเซิร์ฟเวอร์โดยตรงทำให้ RAM และ Swap ไม่เพียงพอ (เกิด Out of Memory / เครื่องค้าง) 
ดังนั้น เราจึงใช้วิธี **"Build โค้ดบนเครื่อง Windows ของคุณ แล้วโยนเฉพาะไฟล์ที่เสร็จแล้ว (Standalone) ขึ้นไปรันบน EC2"** ซึ่งรวดเร็วและไม่กินสเปคเซิร์ฟเวอร์

------------------------------------------------------------------------
คำสั่งทั้งหมดที่ใช้ (รันผ่าน Windows PowerShell)
------------------------------------------------------------------------

1. แก้ไขสิทธิ์การเข้าถึงไฟล์กุญแจ (.pem) เพื่อให้ SSH ได้:
   icacls "C:\Users\ASUS\Downloads\equiptrack-key.pem" /inheritance:r /grant:r "$($env:USERNAME):(R)"

2. สั่ง Build โปรเจกต์บนเครื่อง Windows (แปลงโค้ดให้อยู่ในโหมด Standalone):
   $env:BUILD_STANDALONE="1"; npm run build

3. นำโฟลเดอร์และไฟล์ที่จำเป็นมารวมเป็นไฟล์ `.tar` ขนาดเล็ก (ประมาณ 99MB):
   tar -cf release-small.tar .next/standalone .next/static public prisma package.json pnpm-lock.yaml scripts .env

4. สร้างไฟล์ `Dockerfile.prod` เพื่อให้เซิร์ฟเวอร์นำไฟล์ Standalone มารันโดยไม่ต้อง Build ซ้ำ

5. อัปโหลดไฟล์ที่บีบอัดและ Dockerfile ไปยังเครื่อง EC2:
   scp -i "C:\Users\ASUS\Downloads\equiptrack-key.pem" -o StrictHostKeyChecking=no release-small.tar Dockerfile.prod ubuntu@43.210.64.201:~/

6. ส่งคำสั่งเข้าไปทำงานบน EC2 เพื่อตั้งค่าระบบพื้นฐาน (รันครั้งแรก):
   ssh -i "C:\Users\ASUS\Downloads\equiptrack-key.pem" -o StrictHostKeyChecking=no ubuntu@43.210.64.201 "
     sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile &&
     curl -fsSL https://get.docker.com -o get-docker.sh && sudo sh get-docker.sh && sudo usermod -aG docker ubuntu
   "

7. เปลี่ยนค่า IP ในไฟล์ .env ของโปรเจกต์ (จาก localhost เป็น IP ของ EC2):
   ssh -i "C:\Users\ASUS\Downloads\equiptrack-key.pem" -o StrictHostKeyChecking=no ubuntu@43.210.64.201 "
     sed -i 's|http://localhost:3000|http://43.210.64.201|g' .env
   "

8. สั่งให้ EC2 แตกไฟล์ และรัน Docker Compose ทันที:
   ssh -i "C:\Users\ASUS\Downloads\equiptrack-key.pem" -o StrictHostKeyChecking=no ubuntu@43.210.64.201 "
     cd ~/app && 
     sudo docker compose down ;
     rm -rf ~/app/.next ;
     tar -xf ~/release-small.tar -C ~/app ;
     cp ~/Dockerfile.prod ~/app/Dockerfile.prod ;
     sed -i 's/\.next/#.next/g' .dockerignore ;
     sed -i 's|dockerfile: Dockerfile|dockerfile: Dockerfile.prod|g' docker-compose.yml ;
     sudo docker compose up -d --build
   "

- สร้าง Admin อัตโนมัติ (admin@company.com / admin123)
- เปิดใช้งานแอปพลิเคชัน Next.js ที่ IP http://43.210.64.201 ทันทีครับ!
