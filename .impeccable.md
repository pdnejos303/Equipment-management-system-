# Asset Management — Impeccable Design Context

## Design Context

### Users
Small business owners and operations managers in Thailand who wear many hats. They check the dashboard between meetings, approve bookings on mobile, and scan QR codes on the floor. They're not dedicated IT staff — they need an interface that respects their time, surfaces the right information immediately, and requires zero onboarding. The primary language is Thai, with English and Japanese as secondary locales.

### Brand Personality
**Professional · Reliable · Clean**

Asset Management should feel like a tool that has been thought through carefully — not flashy, but quietly impressive. The tone is calm and confident. It doesn't shout. It informs. When a manager opens the dashboard, they should feel *in control*, not overwhelmed.

Emotional goals: **confidence**, **efficiency**, **trust**.

### Aesthetic Direction
- **Reference:** Linear, Vercel — dark, refined, fast-feeling. Obsessive spacing, crisp typography, minimal but never bare.
- **Anti-reference:** Generic Bootstrap admin panels (gray tables, zero personality), light-mode-heavy UIs (white backgrounds feel outdated and low-contrast for this product).
- **Theme:** Dark-only. Background `#0a0a0a`, surface `#111111`, brand amber `#f59e0b`.
- **Motion:** Smooth, purposeful, never decorative. Staggered entrances for lists. Skeletons over spinners.
- **Density:** Medium — enough information density for a manager scanning quickly, not so dense it feels overwhelming.

### Design Principles

1. **Clarity over decoration** — Every visual element earns its place. No chrome for chrome's sake. If removing it doesn't hurt comprehension, remove it.

2. **Speed as a feature** — The UI should feel instant. Prefer skeleton screens over loading spinners. Prefetch routes. Animate state changes, not loading states.

3. **Data is the hero** — Charts, numbers, and status badges are the point. The UI frames them quietly — it never competes for attention.

4. **Dark, premium, refined** — Inspired by Linear/Vercel: tight spacing, consistent border radius, restrained use of color. Amber accents used sparingly for maximum impact.

5. **Thai-first, globally graceful** — Designed for Thai SMB context (Noto Sans Thai + Inter). Layouts must accommodate Thai text without breaking. EN/JA are first-class citizens, not afterthoughts.

## Component Conventions

- **Cards:** `rounded-xl`, `border border-border`, `bg-surface`, `p-5`
- **Inputs:** `rounded-lg`, dark background, brand focus ring
- **Buttons primary:** Amber fill, black text, `rounded-lg`
- **Animations:** 0.3–0.5s ease-out entrances; staggered lists with 50–80ms delays
- **Icons:** Lucide React exclusively
- **Reduced motion:** All animations respect `prefers-reduced-motion`
